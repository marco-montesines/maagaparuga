# Security Policy

## Reporting a vulnerability

Please report vulnerabilities **privately** via GitHub's private vulnerability reporting
("Report a vulnerability" under the repository's Security tab). Do not open public issues
for security reports.

You can expect an initial response within **7 days**.

## Supported versions

This is a research and educational project; only the latest state of the default branch
is supported. There are no maintained release lines.

## Scope

MaagapAruga is **not intended for production use with real personal or health data**
(see [DISCLAIMER.md](DISCLAIMER.md)). Reports are nevertheless welcome for any weakness
in the code, container images, CI workflows, or infrastructure code — the project treats
security findings as first-class issues regardless of its research scope.
