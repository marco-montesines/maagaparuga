# Mock data

All data in this directory — and everything MaagapAruga ships with — is **fictitious**.

Rules for every persona and record here:

- Names are invented and paired with the marker middle name "Demo" where practical.
- Email addresses use `example.com` / `example.org` only.
- Phone numbers use reserved fictional ranges only.
- Addresses are invented and non-resolvable.
- Vitals, notes, transcriptions, and questionnaire answers are generated samples.

Do **not** replace this data with real personal or health data. See
[DISCLAIMER.md](../../DISCLAIMER.md).
